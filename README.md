# JoulesCalc2AG
Meu primeiro código em Python, Agora disponível pra download em .AppImage

Com interface minimalista escrita em QT6

Esse programa básico em Python calcular os Joules de um carabina de ar comprimido com
base em massa do projetil e sua velocidade, dando o resultado em Joules

A matematica basica por tras disto é m.v²/30860
onde m é peso do projetiil em grais, v² a velocidade inicial ao quadrado 
e 30860 uma constante pra uso de grains ao inves de gramas
